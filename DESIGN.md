# Дизайн-система

Метафора — **корректура**. Эксперт вычитывает карточку поставщика, как редактор вычитывает текст: найденное
отмечено маркером, исправленное — красным карандашом, замечания пронумерованы на полях. Поэтому в интерфейсе
нет «дашборда»: белый лист, чёрные чернила и два смысловых цвета. Своего бренда у модуля нет: в шапке — что он
делает («Автозаполнение характеристик СТЕ», `PRODUCT_NAME` в `frontend/src/layout/Layout.tsx` и `<title>`).

Код: токены — `frontend/src/index.css`, компоненты — `frontend/src/ui/`, каркас — `frontend/src/layout/`.
Живая витрина — страница `/ui`.

## Цвет

Цвет в интерфейсе только тогда, когда он что-то значит. Главная кнопка — чернилами, а не акцентом.

| Токен | Значение | Смысл |
|---|---|---|
| `canvas` | `#eceef0` | стол, на котором лежит лист |
| `surface` | `#ffffff` | лист и панели |
| `raised` | `#f5f6f7` | наведение, связанная строка |
| `line` / `line-strong` | `#dcdfe3` / `#868d98` | разделители / рамки полей (3:1 к белому) |
| `ink` | `#17191c` | текст, главная кнопка, фокус |
| `muted` / `subtle` | `#5b616a` / `#6b717b` | вторичный и третичный текст (оба AA на белом) |
| `mark` | `#ffe98f` | **маркер**: значение найдено в тексте поставщика |
| `pencil` = `danger` | `#c4301f` | **карандаш**: исправлено, ошибка, номер замечания |
| `success` / `warning` | `#2d6a3e` / `#8a5700` | «исправлено», «внимание» — только текстом или мягким фоном |

Контраст: весь текст, включая зачёркнутое и подписи, проходит WCAG AA. Проверено accesslint на всех вкладках `/ui`.

## Шрифты

Все из своих файлов (`@fontsource*`), без Google Fonts: демо работает без интернета. Все с кириллицей.

| Роль | Шрифт | Размер |
|---|---|---|
| Интерфейс | Onest | 13–15, заголовок экрана 26 / 600 |
| Текст документа (описание поставщика) | PT Serif | 17 / 1.75 |
| Коды КТРУ, ОКПД2 | JetBrains Mono | 13–19 |

Засечки только у текста документа: так видно, где исходный документ, а где интерфейс. Числа — `tabular-nums`.

## Правила

1. **Никаких карточек внутри карточек.** Лист документа — единственный элемент с тенью. Внутри панелей строки
   разделяются линиями, а не коробками.
2. **Без бейджей на каждой строке.** Статус значения передаёт типографика: маркер — найдено в описании,
   красное зачёркнутое — было, рядом — стало.
3. **Действия — словами.** Исправление — ссылка «Исправить: указать „Белая“» под замечанием, а не кнопка-таблетка.
4. **Одна заливная кнопка на экран**, чернилами. Остальные — обводка или текст.
5. **Коды — моноширинным**, остальное — нет. Моноширинный не используется для украшения подписей.
6. **Связь текста и карточки.** Наведение на характеристику подсвечивает строку описания и наоборот.
7. **Движение только объясняет:** маркер «прокрашивается» по найденным значениям (`.marker`), полоса прогресса
   идёт по верхнему краю листа во время проверки. Всё выключается при `prefers-reduced-motion`.
8. **Служебного в интерфейсе нет.** Состояние зависимостей — только API (`/api/health/ready`) для эксплуатации;
   пользователь видит сбой там, где он его касается (например, «часть характеристик не извлечена автоматически»).
9. **Без декора:** без свечений, фоновых сеток, градиентов, монограмм в плашках, точек перед строками.

## Компоненты (`frontend/src/ui/`)

| Компонент | Назначение |
|---|---|
| `Button`, `Kbd` | `primary` (чернила) / `secondary` (обводка) / `ghost`; `sm` 32, `md` 36, `lg` 44 |
| `Field`, `Input`, `Textarea`, `Select` | подпись над полем, подсказка или ошибка под ним |
| `Radio`, `Checkbox` | выбор чернилами |
| `Tabs` | подчёркивание чернилами |
| `Badge`, `Notice`, `Skeleton`, `EmptyState` | тихие плашки без рамок; в рабочем экране — только там, где нельзя сказать текстом |
| `Panel` | блок экрана: заголовок, описание, действия справа |
| `Table` | в контейнере уже 576px строки становятся карточками |
| `DefinitionList`, `Steps`, `Dialog` | параметр → значение, этапы, модальное окно |

## Каркас (`frontend/src/layout/`)

- `AppHeader` — белая шапка 52px: название модуля, разделы по ролям («Поставщик», «Модератор»; подпись роли —
  `subtle`, не плашка), справа «Метрики» и «API»; активный раздел подчёркнут.
- `PageHeader`, `PageBody` — заголовок экрана и контейнер 1280px.

## Текст интерфейса

Русский, короткий, без канцелярита и без длинного тире. Замечание: что не так, почему (правило) и чем
исправить — в одном абзаце. Кнопка — глагол.
