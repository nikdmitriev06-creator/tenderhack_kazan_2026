## Что лежит в коде страницы, но скрыто

Страница собрана из шаблона прошлых городов. В HTML-комментариях осталось:

- форма регистрации (кнопки «ПРИНЯТЬ УЧАСТИЕ» закомментированы, регистрация на сайте недоступна);
- блок «Описание кейса — GoogleDrive» со ссылкой выше;
- таблица «Результаты» (CSS-класс `result-ekb` остался от шаблона): 1 место — one-zero-eight (178 баллов),
  2 — TEAzaurus (161), 3 — Сынки плотника (133), 4 — SMARTini (124), 5 — ANYX (102). По mos.ru one-zero-eight
  выиграли Казань 28–30.11.2025 (кейс «групповой подбор СТЕ по характеристикам»), так что это итоги прошлого
  казанского хакатона. Балл выше 100, потому что два этапа защиты по 100 баллов суммируются
  ([../research/tenderhack-patterns.md](../research/tenderhack-patterns.md));
- этап «Презентация кейса задания и исходных данных» с датой 20.10 (от другого города);
- карточка эксперта Копьевой Александры (контроль качества работы Портала поставщиков).
